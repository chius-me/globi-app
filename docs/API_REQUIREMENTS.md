# API 需求与契约管理

本文档用于前端同学向后端同学提出新的接口需求、字段修改或 API 行为变更。

## 协作流程
1. 前端同学在此文档底部添加新需求，包含接口路径、用途、请求参数和期望的响应格式。
2. 提交代码并通知后端同学查看。
3. 后端同学确认后开始开发，前端可同步进行 Mock 开发。

## 需求列表

*(请按最新需求在最上方的顺序添加)*

### 获取家属列表 (GET /api/blind/families)
- **提出人**: 前端测试
- **状态**: 待开发
- **用途**: 盲人模式下，获取绑定的家属列表，用于语音播报或快捷呼叫选择。
- **Request Headers**: 需要携带 Token
- **Response 期望**:
  ```json
  [
    {
      "id": "1",
      "name": "儿子",
      "phone": "13800138000"
    }
  ]
  ```

### 示例：获取用户状态 (GET /api/user/status)
- **提出人**: 前端
- **状态**: 待开发
- **用途**: 首页展示用户当前是否在线、最后活跃时间。
- **Request Headers**: 需要携带 Token
- **Response 期望**:
  ```json
  {
    "online": true,
    "lastActiveAt": "2026-05-22T10:00:00Z"
  }
  ```
